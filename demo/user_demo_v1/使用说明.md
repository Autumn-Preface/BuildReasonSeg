# BuildReasonSeg 建筑空间推理分割 Demo

## 1. Demo 是做什么的

选择一张包含建筑的航拍或卫星图片，输入一句空间指令。程序先向您确认理解，再生成建筑分割结果。您可以对照原图查看 Overlay 和 Mask。

## 2. 当前支持什么类型的图片

使用 RGB 光学遥感图片，文件类型为 PNG、JPG/JPEG 或 TIF/TIFF。RGBA 图片会去掉透明通道；支持的 16 位 RGB 图片按固定比例转换为 8 位。原图文件不会被修改。

灰度、雷达、红外、未经处理的多光谱图片不受支持。较大的图片会由内部程序分块处理，但参考建筑和周围目标须满足现有分析范围限制。清晰且建筑尺度适中的图片更适合人工查看结果。

## 3. 当前支持的四类指令

- 最大建筑左侧最近的建筑
- 最大建筑右侧最近的建筑
- 最大建筑上方最近的建筑
- 最大建筑下方最近的建筑

参考对象固定为最大建筑。颜色、第二大、第二近、多对象复杂关系等超出当前能力范围。示例按钮只把文字填入输入框，仍需经过语言模型理解和您的确认。

## 4. 如何启动

双击本文件夹中的 **启动BuildReasonSeg Demo.bat**。等环境检查完成后开始操作。程序使用这台电脑已配置好的 Python、GPU 和运行依赖；本文件夹没有附带这些运行环境，也不会联网安装或下载模型。

如需指定其他已配置好的 Python，可设置环境变量 `BUILDREASONSEG_PYTHON` 为该环境的 python.exe 路径。环境不兼容时，程序会给出提示并停止。

## 5. 如何选择图片

点击“选择图片”，找到您的 RGB 遥感图片。左侧显示缩小后的原图预览；缩放仅用于显示。选择另一张图片时，点击“重新选择图片”。

## 6. 如何输入指令

在“空间指令”框中输入上述四类指令之一，也可以点击方向示例填入文字。检查文字后点击“开始分析”。运行期间不要重复点击；程序一次只分析一张图片。

## 7. 如何确认系统理解

程序显示“参考对象、方向关系、目标关系”，请核对后选择是否继续。选择“否”不会进行图像推理。

如果原指令无法直接对应当前能力，系统可能给出替代建议。只有您明确接受建议才会继续；建议可能与原意不同，请逐项核对方向和关系。

如果语言模型不可用，会先询问是否进入有限兼容模式。该模式只支持有限的指令匹配，需要您的明确许可，并会再次显示理解供您确认。

## 8. 如何查看结果

流程完成后，左侧保留原图，右侧显示 Overlay。下方显示输入指令、理解的关系、运行状态和耗时。点击“查看 Mask”打开黑白分割图；点击“打开结果文件夹”查看本次保存的文件。

## 9. Mask 和 Overlay 分别是什么

**Mask** 是黑白图片：白色表示模型生成的目标区域，黑色表示其余区域。

**Overlay** 把模型生成的区域以半透明颜色叠加在原图上，方便人工检查位置。两者均是模型输出，不是人工标注的正确答案。

## 10. results 文件夹在哪里

它就在本 Demo 文件夹内。每次运行使用独立的时间和图片名文件夹，名称冲突时增加编号，不覆盖已有结果。

成功运行保存 `overlay.png`、`mask.png` 和 `result_summary.json`。摘要是供您查看的简化记录，区别于内部原始运行记录。未完成的运行只保存失败摘要，不会生成虚假的 Mask 或 Overlay。

## 11. 常见错误及处理

| 提示 | 可以做什么 |
| --- | --- |
| 图片不受支持或无法读取 | 检查图片是否损坏，是否为受支持的 RGB 光学图片。 |
| 没有检测到可用建筑 | 对照原图检查建筑是否清晰、尺度是否合适。 |
| 没有满足条件的参考建筑 | 当前图片无法满足参考选择条件，请人工检查图片内容。 |
| 所需方向不在可分析范围内 | 检查周围建筑与指令方向是否符合当前范围限制。 |
| 没有生成有效目标 Mask | 本次分析未完成，不能把结果当作正确分割。 |
| 指令不受支持 | 使用四类示例，或核对系统给出的替代建议。 |
| 模型或环境不可用 | 点击“环境检查”，确认完整 Demo 文件夹和已配置的运行环境。 |
| 显存不足 | 关闭其他占用显存的程序，等资源可用后再由您决定下一次操作。 |

“错误详情”提供简短说明与错误代码。程序不会自动重跑失败操作。

## 12. 当前能力边界

这是当前能力的本地演示。最大建筑的自动选择、语言理解、目标关系和分割均可能出现错误；不保证任意城市、任意尺度或复杂指令都能得到正确目标。

您可以整体移动本 Demo 文件夹到这台已配置好的电脑的其他可写位置，保留内部文件结构即可。换到另一台电脑仍需另外配置 Python、GPU 驱动与依赖；不支持跨电脑免配置启动。

请保留完整文件夹，不要单独搬动模型或内部程序文件。临时缓存位于内部 `_runtime_cache` 文件夹，不需要您手动操作。

## 13. “流程完成”不等于“语义结果一定正确”

程序显示“推理流程已完成。结果已生成，请结合原图人工核验目标是否正确。”这表示流程通过了当前结构与方向检查，**不表示目标建筑身份或最近关系已被自动验证**。本 Demo 不读取人工真值；请始终结合原图、指令和周围建筑检查结果。

## 14. 如何关闭程序

点击窗口右上角关闭按钮。分析或检查尚未结束时，请等待完成后再关闭；程序不会强行终止正在进行的操作。关闭窗口后，已保存的结果仍保留在 results 文件夹中。
