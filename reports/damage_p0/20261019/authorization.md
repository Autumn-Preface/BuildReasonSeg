## 一、任务背景与核心目标

BuildReasonSeg 已结束以建筑空间关系指代分割为核心的旧研究阶段，现正式转向建筑外立面可见损伤识别与分割。

本项目继续使用原有项目名称：

**空间推理引导的建筑物结构 MLLM 相关推理分割方法**

新阶段不强制继承旧系统的 YOLO 检测器、D-B1 分割解码器或空间关系场，也不预设 SAM2、SAM3 或其他模型为最终主干。

研究重点为无人机 RGB 建筑外立面影像中裂缝、表面剥落等损伤的细粒度视觉特征表达与分割。

主要关注：

- 颜色、纹理与局部对比度。
- 不规则边缘与细小损伤结构。
- 裂缝连续性、分支和局部几何形态。
- 损伤区域与相似背景的可分性。
- 不同尺度、不同光照及复杂背景条件下的鲁棒性。

MLLM 的自然语言理解及空间推理能力属于后续研究方向，不作为本阶段基础视觉模型研发的前置条件。

### P0 最终目标

完成具有可核查证据的研究准备工作，形成：

1. 数据集调查与可用性结论。
2. 相关论文及现有算法研究报告。
3. 候选模型、公开代码和权重清单。
4. 本地计算环境与存储能力核查报告。
5. 公平、可复现的基线比较实验协议。
6. 值得进一步验证的研究问题与潜在创新切入点。
7. 新研究工作区和持续存储管理制度。

P0 不以获得高分割精度、开发完整 Demo 或训练出新模型为目标。

## 三、工作包 P0-A：公开数据集调查

### 3.1 优先调查对象

首先调查：

- CUBIT-InSeg 及其对应论文、数据与标注资源。
- 建筑外立面裂缝分割公开数据集。
- 混凝土及墙体表面剥落分割数据集。
- 其他与建筑外立面可见损伤高度相关的公开数据集。

数据集名称、内容与可用性必须通过原始论文、官方仓库、发布平台或可信来源核实。

不得因为数据集名称与任务相似，就直接认定它适合本项目。

允许发现并补充更合适的数据集，不强制使用 CUBIT-InSeg。

### 3.2 每个数据集必须调查

- 数据集名称、版本、论文与来源。
- 影像拍摄方式及使用场景。
- RGB、深度或其他模态类型。
- 图像数量与分辨率分布。
- 损伤类别及标签定义。
- 语义掩码、实例掩码、多边形或其他标注形式。
- 官方训练、验证、测试划分。
- 数据下载条件及使用许可证。
- 是否存在场景、建筑物或拍摄序列重叠。
- 是否包含无人机视角或可迁移至无人机视角的数据。
- 是否适合裂缝、剥落等目标的独立分割评价。

### 3.3 数据真实性检查

对可以合法、正常获取的数据集，进行必要的小规模抽样检查。

检查内容包括：

- 原始图像能否正常读取。
- 标注能否正确解析并与图像配准。
- 损伤标签与实际可见区域是否一致。
- 细小裂缝在原始分辨率下是否可辨认。
- 是否存在明显漏标、模糊边界或类别歧义。
- 是否存在无法直接比较的标注定义差异。

可制作少量图像与标注叠加示例，作为调查证据。

不得提前大批量下载全部候选数据集。

不得用模型生成的伪标签冒充人工真实标注。

### 3.4 数据集决策结论

形成数据集候选比较矩阵，说明：

- 适合训练的数据集。
- 适合跨数据集验证的数据集。
- 只能作为辅助研究材料的数据集。
- 不建议使用的数据集及原因。

如现有数据集不足以同时支撑裂缝与剥落研究，应明确指出这一限制，不得自行修改研究目标来掩盖问题。

**交付：** 数据集调查报告、结构化数据集清单、抽样检查证据与数据风险说明。

## 四、工作包 P0-B：相关论文与研究空缺调查

### 4.1 文献方向

重点调查近年公开发表的工作，并适当追溯重要基础方法。

覆盖：

1. 建筑外立面损伤检测与语义分割。
2. 裂缝细粒度结构识别与分割。
3. 表面剥落、缺损及复杂背景分割。
4. 纹理、边缘及多尺度视觉特征建模。
5. 小目标、细长目标及边界监督方法。
6. SAM 系列在专业损伤分割中的应用与局限。
7. 相关领域的轻量化或专用分割架构。

### 4.2 文献记录要求

对主要论文记录：

- 标题、作者、年份、发表来源。
- DOI、论文链接或其他可验证标识。
- 研究任务及使用数据集。
- 核心算法或结构变化。
- 主要技术贡献。
- 采用的评价指标。
- 论文报告的实验结果。
- 方法的限制及可复现条件。
- 是否提供开源实现及预训练权重。

论文原始结果与本项目实测结果必须严格区分。

不能将不同数据集上的 IoU 或 F1 直接作为模型优劣排序依据。

优先阅读与本项目任务高度相关、技术方法可分析的论文，而不是单纯追求论文数量。

### 4.3 创新性调查

特别检查以下技术是否已存在充分的先行研究：

- 边缘与纹理联合特征提取。
- 多尺度特征融合。
- 裂缝连续性约束。
- 边界感知损失。
- 注意力机制增强。
- 特定损伤类别的先验建模。
- 基于视觉基础模型的损伤提示分割。

**上述技术不能因为被重新组合，就自动认定具有创新性。**

形成“已有方法—解决问题—尚存不足—可能验证方式”对应表。

当前只能提出候选研究问题或创新假设，不得宣布最终创新模块已经确定。

## 五、工作包 P0-C：候选模型及开源资源调查

### 5.1 候选范围

至少考虑以下模型类别：

| 模型类别 | 代表候选 |
|---|---|
| 经典语义分割 | U-Net 及合理变体 |
| Transformer 分割 | SegFormer |
| 提示式分割 | SAM2、SAM3 |
| 实例分割 | YOLO 实例分割系列 |
| 领域专用方法 | 建筑损伤、裂缝或剥落专用分割模型 |

这里列出的是候选范围，不代表要求全部训练。

具体版本必须依据官方发布记录和可获得资源核实，不得使用未经验证的模型名称或功能声明。

### 5.2 模型调查内容

每个候选需要记录：

- 论文与官方项目来源。
- 官方实现或可验证的实现。
- 预训练权重是否公开。
- 代码及权重分别适用的许可证。
- 所需 Python、PyTorch、CUDA 版本。
- 典型输入尺寸、显存及计算需求。
- 对损伤分割任务的适配难度。
- 是否需要额外检测器、提示或人工输入。
- 可否直接进行无提示全自动推理。
- 是否有可复现的训练和评估入口。

严禁将第三方修改版本误称为官方实现。

### 5.3 对提示式分割的特别要求

必须明确区分：

**A. 人工真实提示**

由人工提供真实目标位置或范围，作为提示条件下的分割表现。

**B. 自动生成提示**

由检测器、自动定位模块或其他不依赖测试真值的方法提供提示。

**C. 文本提示**

通过模型实际支持的文本条件接口进行目标指定。

三种方式不能混为一个基线。

是否支持文本提示必须针对具体模型版本核实。

测试阶段使用 Ground Truth 生成的框或点，只能属于明确标注的 Oracle/上界实验，不能称为全自动分割结果。

### 5.4 候选筛选结论

综合任务适配性、开源条件、计算成本及实验公平性，推荐一个规模可控的 P1 候选集合。

建议考虑约 3—4 条有代表性的比较路线，但以研究证据为准，不强行凑数量。

推荐必须有明确理由。

**本阶段不进行候选模型的大规模训练，也不提前选定最终主干。**

## 七、工作包 P0-E：正式实验协议设计

本工作包是 Damage-P0 的核心交付之一。

### 7.1 任务定义

以建筑外立面 RGB 可见损伤分割作为核心任务。

明确：

- 裂缝与剥落是否采用独立类别。
- 背景及其他损伤如何处理。
- 二分类与多类别分割的适用条件。
- 不同数据集标签如何映射。
- 对无法统一的标注如何处理。

不得通过不合理合并类别来制造更高指标。

### 7.2 数据划分

优先沿用可靠的官方划分。

如果需要重新划分，必须防止：

- 同一建筑不同角度影像跨集合泄漏。
- 同一无人机航线连续帧跨集合泄漏。
- 重叠图块跨集合泄漏。
- 同一原始大图的不同裁剪区域跨集合泄漏。

明确训练、验证和测试的职责。

测试集不得参与超参数选择、提示调节、模型筛选或阈值优化。

### 7.3 基线分组

设计至少三类相互独立的比较协议：

**Group A：全自动损伤分割**

输入为 RGB 图像，不额外提供测试真值或人工目标位置。作为后续视觉特征创新的主要比较对象。

**Group B：提示式损伤分割**

针对实际支持相应输入的模型，分别评估人工/真实提示、自动提示等设置。提示预算、来源和生成规则必须固定。

**Group C：文本引导分割的预留协议**

仅建立后续扩展定义与评估接口，不要求 P0 实现 MLLM 或文本分割模型。

不同组可以分别报告，但不能在缺乏相同输入条件的情况下直接比较为同一个排行榜。

### 7.4 指标体系

至少定义：

- IoU / mIoU。
- Dice / F1。
- Precision。
- Recall。
- 不同损伤类别的独立指标。
- 小面积损伤的召回表现。
- 推理耗时与显存开销。

建议额外研究：

- 边界 F1 或适合细长裂缝的边界指标。
- 裂缝连通性相关评价。
- 按损伤面积分层的指标。
- 不同背景复杂度下的表现。

需要明确指标公式、统计单位、阈值、空掩码处理方式以及宏平均、微平均或按像素加权的计算口径。

不要求所有附加指标都成为 P1 强制指标。

小损伤的面积阈值应在正式实验前依据数据分布确定，不能观察测试结果后临时修改。

### 7.5 公平性与可复现性

协议需要明确：

- 图像输入分辨率和裁剪策略。
- 数据增强及其适用范围。
- 预训练条件。
- 模型训练预算。
- 优化器与学习率管理原则。
- 验证集选择规则。
- 随机种子与重复实验安排。
- 测试结果统计方式。
- 推理硬件和耗时测量方式。
- 不同标注形式的转换规则。

区分：

1. 公平的模型能力比较。
2. 公平的端到端系统比较。
3. 不同提示或监督条件下的诊断性比较。

对于不能完全统一训练配置的模型，应记录实际差异，不得假装所有条件完全相同。

P0 只建立正式协议草案，完成 ChatGPT 审查后再冻结为 P1 的实验依据。

## 八、工作包 P0-F：研究问题与潜在创新切入点

在数据、论文和候选模型调查完成后，整理具有证据支持的研究假设。

重点考察：

- 复杂背景下损伤纹理与背景纹理的区分问题。

- 剥落区域不规则边缘的预测偏差。

1. 已有论文如何处理这一问题。
2. 当前仍有哪些未解决的局限。
3. 哪些数据和指标能够验证该局限。
4. 可以构建怎样的受控对照实验。
5. 是否存在真实而独立的创新空间。

**本阶段禁止直接实施新算法模块。**

允许在报告中提出多个创新方向及优先级，待 P1 基线结果出现后再进一步筛选。
