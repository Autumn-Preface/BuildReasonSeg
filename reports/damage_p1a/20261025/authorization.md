# DAMAGE-P1A 授权记录

来源：项目负责人在本 Codex 对话于 2026-10-25 发出的《建筑损伤视觉特征识别：数据准入与首个训练基线》任务书。下文为可执行范围摘录，不冒充 P0 已验收或历史任务原文。

项目：BuildReasonSeg；执行者 Codex；监督及验收 ChatGPT Supervisor。

- 独立研究 RGB 建筑表面 crack 与 spalling 两个独立分割通道。
- 从包含最新可信 P0 成果的状态创建 `research/damage-p1a-visual-baseline-20261025`，不从滞后 main 开始。
- 首先审查 CUBIT-InSeg 官方版本、许可、类别 ID、实际尺寸/类别分布、官方 split、重复/近重复、建筑分组、多边形配准和文件哈希。不能凭文件名推断类别。权威映射无法确认则停止正式训练准入。
- 下载前完整空间预算，保持系统余量。新数据/权重/缓存/输出隔离，不清理旧资产。官方 test 不重分、不用于调参，不读测试预测来选择模型。
- 建立独立 Conda 环境 `.conda/buildreasonseg-damage-p1a`，验证 RTX GPU/CUDA 运算，记录依赖、时间和显存。不升级驱动、不破坏旧环境。
- 建立可复用数据转换、加载、图块坐标、重叠/空 Mask/未知通道 ignore、原图概率重建和独立指标。不能用图块平均 IoU 冒充原图结果。
- 基线为标准 U-Net，从头训练，RGB→两独立概率；固定 BCEWithLogits+Soft Dice、AdamW、512²图块、种子；仅按 val 选 best。先真实小烟测，再一个开发种子，至多 60 epoch/12 GPU 小时。
- 建筑/航线信息缺失时可保留明确局限的探索性 train/val；不能声称跨建筑泛化。重大准入/资源/评价问题可只完成数据与工程，不强行训练。
- 真实 val 输出上的初步错误分析须展示真实失败和统计，不挑删失败样本，不凭少量案例下泛化结论。
- 交付数据准入报告、可运行代码/冻结配置/日志、仅在门禁通过后的真实 checkpoint/验证结果、错误分析和完整 Markdown 工作报告；源码和小证据推送独立 GitHub 分支，大数据/完整权重不进 Git。
- 禁止 MLLM 选型训练、空间架构修改、旧 RC1/V3/P0/正式实验修改、创新模块设计、测试集调参、伪造结果、自行验收或自动进入 P1B/P2。
