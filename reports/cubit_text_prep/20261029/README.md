## 可重跑与实际成本

在既有 P1A Python/NumPy/Pillow 环境运行，不安装或修改依赖。scan.py 的 --source/--repo/--out 可指定；out必须为不存在且位于数据源以外的新目录，拒绝覆盖。supplement.py 和 finalize.py 用于复现本轮有界补样和已记录的视觉筛选决定；复跑补样须使用新任务副本，因为输出目录拒绝覆盖。finalize不是新的人工审核。

成功主扫描45.192秒，计数读取1,834,113,696源文件逻辑字节（标签全量及42候选原图），仅42张图像算SHA；8张补样1.101秒，另读23,444,201逻辑字节。Pillow头部读取、候选生成时重复读标签及派生文件读取未计入此字节数；不是物理磁盘吞吐测量。独立复核成本另在 review/ 中保存，应与主扫描相加，不能隐去。

首轮因 utf8-sig 编码别名拼写错误在第一份标签后停止（1.54秒，已读213449字节），失败目录 derived 保留，未覆盖；修正为utf-8-sig后在 derived_run2 成功。原扫描器坏token会抛错而非隔离，独立复查发现后已加异常捕获和token数量校验，7项对抗测试通过。主扫描结果在修复前已成功读完全部真实标签，当前修复不改变已生成的数据。未为了测试而重复全库扫描。
