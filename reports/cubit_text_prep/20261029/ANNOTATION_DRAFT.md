# 人工试标注规范草案 v0.1（待 Supervisor 审定）

本阶段交付候选，不表示已经完成人工文本标注。正式试标注仅使用最终清单中 train 原图；官方 test 不展示、不挑样、不用于修改规范。本项目与华为 CodeArts Space > 代码开发 > 智能体独立，AgentTeam 未启用。

## 原图、GT 与审核衍生物

原始 JPG/TXT 永久只读。预览是缩略图加原多边形线条与行号，明确标为非 GT；不是预测，也不替代原分辨率 GT。实例单位是原 TXT 的一行多边形，不能假定它必然等于一个完整物理损伤。相邻碎片是否属于同一损伤必须复核；一个指令可绑定多个原实例，但应保存集合和理由。

image_id = 数据版本/官方 split/原文件 stem；instance_id = image_id/原始行号/行文本 SHA256 前16位。完整 label_sha256、line_sha256 与坐标另存，检查冲突和标签版本。哈希以原始字节为依据；行哈希以解码后不含换行符的 UTF-8 文本为依据，二者不可混称。原图 SHA256 仅对候选现算；其余图像保持 null，后续按需补充，不冒充全库已验证。

## 每图工作顺序

1. 先看原图，记录可见损伤、参照物、遮挡、模糊、边缘截断及目标是否可辨；再显示叠加图检查错位、漏标、过标、碎片化。
2. 不依据 CR/SP 文件名前缀或数字 ID 自动命名类别。数字 ID 属内部元数据。人工视觉命名是 provisional_visual，不等于官方映射证实。取得带来源/版本/哈希的作者类别配置后才能改变 mapping_status。
3. 对有效域单独标记：unknown / target_only_verified / class_region_verified / full_image_verified。默认 unknown；同图只有一个数字类别不能推导另一类别不存在，未标区域也不能当负样本。无充分审核禁止“所有裂缝/所有剥落”指令；只允许边界和实例集合清楚的目标描述。
4. 直接分割：目标外观和范围明确；限定单个或经复核的实例集合，避免把全图不完整 GT 当全集。位置指代：说明以图像坐标为准，复核其他同类目标是否同样符合“右上”等词。
5. 空间关系：先人工标出参照物（独立 review_reference，必要时 bbox/polygon），再写关系和目标。最近/最大等词需要明确比较集合及计量语义，不能只看自动框中心排序。若需三维距离、结构安全或不可见上下文，一律退回。视觉语义推理只使用图像可观察证据；记录推理链与替代解释，禁止臆断成因/危险等级。
6. 每条草稿保存 instruction_text、target_instance_ids、reference_annotations、relation_evidence、ambiguity_flags、valid_domain、author、reviewer、时间和版本。至少另一人盲读原图与指令，独立指出目标，再对比实例。单人实施可隔日复核但不能声称独立双人一致。
7. 状态仅可 draft -> needs_clarification / rejected / accepted_pending_supervisor。驳回必须有原因；修改保留事件记录。待核验类别映射、漏标、参照物或多目标歧义未解决时，不得导出正式训练数据。

## 隔离规则

全部历史重复候选成员（包括同 split 重复）退出试标注候选池。已确认 SHA256 证据与 CRC32 候选分开保存。候选排除不改官方 split；不宣称已消除建筑级或近重复泄漏。

零面积多边形按行保留异常记录；包含异常的整张图退出本轮候选。后续可另建修订建议，不删除原行、不重绘原 GT、不自动将零面积实例变成背景或空目标。自交、重叠、断裂、像素栅格退化尚未完整审计，人工仍需原分辨率检查。

## 试标注计划和记录

建议首轮40图，每图先尝试一条直接指令、一条位置指令；具备真实上下文的图再尝试关系/视觉语义指令。不设必须完成的复杂指令数量。记录每图实际分钟数、可用任务类型、退回原因、双人一致率和复杂任务成功产出比例。40图是目的性试标注样本，不用于估计全库性能或证明复杂推理覆盖率。

## 模型输入隔离

内部记录与模型输入采用两个独立对象。未来导出只能白名单复制 image（内容或中性ID）和经审核 instruction_text。内部 task_family、numeric_class_id、文件名前缀、筛选分层、目标ID、框、关系真值和答案均不得拼进指令或图片上的提示标记。训练目标 Mask 是独立监督字段，不是指令的一部分。本轮不实现正式导出、不批量生成指令。
