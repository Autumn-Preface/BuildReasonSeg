## 0. Evidence policy and verification status

### 0.1 Evidence-priority rule actually used

`official repo / model card / dataset card  >  official paper (arXiv / publisher / venue) / official project page  >  official documentation (vendor docs, package index, platform API)  >  secondary`

Applied consistently with three hard sub-rules carried over from the raw files:

1. **A paper licence is never evidence for code, weights or data.** arXiv/CVF/ISPRS paper licences (e.g. LISA = CC BY-NC-SA 4.0, SegLLM = CC BY 4.0) are recorded as *paper* licences only.
2. **A licence is only as strong as the artefact it was read from.** A `LICENSE` file or platform licence field outranks a model-card snippet; a search-result snippet, blog, aggregator or mirror is **never** licence evidence.
3. **Code licence ≠ weight licence ≠ dataset licence.** They are recorded in separate columns throughout §3.

### 0.2 Verification labels (exactly three, used in the `Verification` column)

| Label | Definition |
|---|---|
| `VERIFIED_FIRST_HAND` | The page/file **body was actually retrieved and read**. Includes negative results where the page was retrieved and shown to say nothing (e.g. VRSBench's absent data licence) and first-party 404/500 API probes. |
| `PLATFORM_FIELD` | The value comes from an **official platform API field** — a Hugging Face API `license:` tag, a ModelScope `License` / `Data.License` field, a GitHub API `license.spdx_id`. Strong, but **not** the same as reading a `LICENSE` file. |
| `UNVERIFIED` | The page **could not be retrieved** (or the retrieved body carried no usable content); **nothing is asserted**. For licence cells this is written out in full as `UNVERIFIED / DO NOT USE UNTIL RESOLVED`. |

**Labelling of the pre-verified licence values.** The values themselves are carried through unchanged: `facebookresearch/segment-anything` and `facebookresearch/sam2` code = Apache-2.0 from a `LICENSE` file read → `VERIFIED_FIRST_HAND`; `dvlab-research/LISA`, `mbzuai-oryx/groundingLMM`, `MaverickRen/PixelLM`, `LeapLabTHU/GSVA` = Apache-2.0 with their star/push figures → `PLATFORM_FIELD`, because the prompt's own definition of that label names a GitHub API `license.spdx_id`; all Hugging Face API `license:` tags → `PLATFORM_FIELD`; `Qwen/Qwen2.5-VL-3B-Instruct` (no tag, empty ModelScope field) → `UNVERIFIED / DO NOT USE UNTIL RESOLVED`. Reading a `LICENSE` file is *stronger* than reading an API field, and the two are never conflated in §3.

**Convention for third-party relays.** Where a raw file obtained official content only through a third-party relay (`ghproxy.net` for `raw.githubusercontent.com`; `hf-mirror.com` for the Hugging Face API; `mintlify.wiki` for Qwen docs), the row is labelled `UNVERIFIED` even though relayed bytes were seen, because the registered URL is **not** the official page and every raw file rules mirrors inadmissible for licence or asset facts. The relay is named in `Source type`. These rows are **leads, not evidence**.

**Convention for dedup.** One row per **distinct URL string** across all six raw files. A URL appearing in several raw files is one row; the `Supports which claim` cell merges all uses. Ellipsis/glob templates in the raw files (e.g. `…/raw/main/config.json` for three Qwen3-VL repos, `https://raw.githubusercontent.com/<org>/<repo>/main/LICENSE`) are **not** enumerated — they are search instructions, not URLs.

## 1. Network reachability ground truth (2026-09-26)

The six raw files disagree about which hosts are reachable. The following is the reconciled, verified account; §4.6 records each contradiction and its resolution.

### 1.1 The `hosts`-file blackhole (verified)

- `C:\Windows\System32\drivers\etc\hosts` — **210 blackhole entries, last written 2026-09-26** — maps `github.com`, `raw.githubusercontent.com`, `huggingface.co`, `github.io` and many CDN/asset hosts to `127.0.0.1`.
- The blocklist is a **Steam++ / Watt Toolkit** blocklist (`# Steam++ Start` / `# Steam++ End` markers), independently read from the file by `_raw/datasets.md` §0.1.
- **Apex `github.io` is mapped to localhost, but sub-domains are not** (`captain-whu.github.io`, `gcheng-nwpu.github.io`, `vrsbench.github.io`, `earth-insights.github.io`, `pixellm.github.io`, `mbzuai-oryx.github.io`, `lxtgh.github.io`, `zhouyiks.github.io` all rendered). This fully explains the blackhole/no-blackhole disagreement between raw files.

### 1.2 Reality: a transparent local proxy makes those hosts work for ordinary clients (verified)

Despite the `hosts` blackhole, **a local listener on `0.0.0.0:443` transparently proxies those connections**, so ordinary HTTP clients DO receive real upstream content. Verified first-hand:

| Probe | Result |
|---|---|
| Python `urllib` → `https://huggingface.co/api/models/Qwen/Qwen3-VL-4B-Instruct` | **genuine JSON returned** |
| `https://raw.githubusercontent.com/facebookresearch/sam2/main/LICENSE` | **real Apache-2.0 text returned** |
| `git ls-remote https://github.com/facebookresearch/sam2 HEAD` | **succeeded** |
| GitHub API `license.spdx_id` reads for `dvlab-research/LISA`, `mbzuai-oryx/groundingLMM`, `MaverickRen/PixelLM`, `LeapLabTHU/GSVA` | **returned** (Apache-2.0) |
| Hugging Face API `license:` tags for the Qwen3-VL and Sa2VA families | **returned** |

### 1.3 The DSH `web_fetch` / `web_search` tools are the exception (verified)

The DSH `web_fetch` / `web_search` tools **cannot** fetch those hosts: they refuse hostnames resolving to non-public IPs (`URL hostname … resolves to a non-public IP address`). **Every "host unreachable" label in the raw files is therefore a tool-level label, not a network-level fact.** Where a licence was later verified through the proxy/API, the verified value is preferred in §2 and §3 — that is why the raw files' empty licence register is not reproduced here.
