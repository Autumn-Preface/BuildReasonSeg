# 本地人工审核入口

双击本目录 **start_review.cmd**，浏览器会打开 `http://127.0.0.1:8765`。使用仓库现有 `.conda/buildreasonseg-damage-p1a/python.exe`，不安装依赖、不访问云端。若端口被另一任务占用，先关闭那个服务；不要改原数据或清理未知进程。

1. 在左侧选图，先关叠加看原图，再开轮廓/Mask 对照。滚轮缩放、拖动平移；“原图 100%”为一原图像素对一画布逻辑像素。细线边缘请放大查看，不能只凭适应画面作判断。
2. 勾选左侧实例可组合目标；“定位”放大该实例。行号/稳定 ID/原数字类别用于内部核对，不能复制进指令。
3. 填写真实操作人和自然语言草稿。审核人可暂空。状态只有草稿/需澄清/退回/待人工审核；没有正式确认入口。
4. 若用参照物，先填名称，再选“绘制参照物框”并在图上拖框。选择目标集合和参照物后填写关系及比较范围，点击关联。有效域/未知区域也可拖框，均只是待审核建议。要修改几何请移除后重画；有关系依赖时先移除关系。任意形状可用多个矩形近似并在备注记录局限，本轮不提供参照物多边形编辑器。
5. 标记歧义，记录实例组合理由、漏标疑虑、遮挡/截断、关系替代解释。原始数字类别语义始终 unconfirmed；临时视觉类别仅为观察。
6. 点击“保存新版本”。草稿 JSON 在本目录 `drafts/<图像key>/<草稿ID>/rev-xxxxxx.json`，每次保存保留完整新版本与历史。切图或关闭前先保存；未保存文字不会自动持久化。多窗口旧版本保存会报冲突，重载后人工合并。
7. 下次选图，在“已有指令草稿”选记录再点“重载”；同图可“新建另一条指令”。旧版本 JSON 可直接查看对比；当前 UI 重载最新版本。草稿损坏/哈希不一致会报错，勿手动覆盖原版本。会话无密码，仅监听本机；请勿转发端口。

`qa_drafts` 为执行者工程测试，里面的 TOOL_TEST_NOT_HUMAN 和占位文本都不是标注。正常入口使用空的 `drafts`，不会带入测试记录。草稿默认不提交 Git，以免把未审核内容当正式数据；请定期复制整个 drafts 文件夹到自己的备份位置，版本文件不可选择性覆盖。无需复制原始图像。

关闭浏览器不停止本地服务。可在 PowerShell 中运行 `Stop-Process -Id (Get-Content -LiteralPath .\research\cubit_text_pilot\drafts\server.pid)` 停止由入口启动的那个进程；先核对 PID 对应本工具，PID 复用时不要执行。服务重启后 JSON 仍保留。也可前台运行并 Ctrl+C：

```powershell
& ./.conda/buildreasonseg-damage-p1a/python.exe -B research/cubit_text_pilot/server.py
```

本工具不修改原始 JPG/TXT，也不导出训练集、自动生成指令或确认标注。详细限制和逐图问题见任务报告。
